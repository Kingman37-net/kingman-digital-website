# KDCN Incident Response Plan

**Classification:** INTERNAL — SOURCE OF TRUTH

## 1. Purpose
Procedures for detecting, responding to, and recovering from security incidents.

## 2. Incident Classification
| Priority | Description | Response Time |
| :--- | :--- | :--- |
| P1 — Critical | Data breach, service outage | Immediate |
| P2 — High | Unauthorized access | < 1 hour |
| P3 — Medium | Suspicious activity | < 4 hours |
| P4 — Low | Minor issues | < 24 hours |

## 3. Response Process
1. Detection & Reporting
2. Triage & Classification
3. Containment
4. Investigation & Analysis
5. Eradication
6. Recovery
7. Post-Incident Review

## 4. Communication
- Internal: Incident Commander notifies leadership.
- External: Communications Lead notifies affected parties.
- Regulatory: Legal/Compliance Lead notifies regulators.
