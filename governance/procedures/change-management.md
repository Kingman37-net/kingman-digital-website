# KDCN Change Management Procedure

**Classification:** INTERNAL — SOURCE OF TRUTH

## 1. Purpose
Manage changes to KDCN systems in a controlled manner.

## 2. Change Types
- Standard: Routine, pre-approved
- Normal: Require review and approval
- Emergency: Urgent fixes

## 3. Change Process
1. Request change.
2. Review and impact assessment.
3. Approval.
4. Implementation with rollback plan.
5. Post-implementation review.
