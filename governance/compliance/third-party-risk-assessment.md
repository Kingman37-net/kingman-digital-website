# KDCN Third-Party Risk Assessment

**Classification:** INTERNAL — SOURCE OF TRUTH

## 1. Purpose
Process for assessing risks associated with third-party service providers.

## 2. Assessment Criteria
- Data Security
- Compliance
- Access Controls
- Breach History
- Sub-Processors

## 3. Current Providers
| Provider | Service | Risk Level |
| :--- | :--- | :--- |
| GitHub | Code hosting | Low |
| Formspree | Contact forms | Low |
| Google Analytics | Analytics | Low |

## 4. Review Process
- Initial Assessment: Before onboarding
- Annual Review: Yearly
- Incident Review: After any security incident
