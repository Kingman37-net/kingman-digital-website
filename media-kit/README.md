## 🎨 Brand Colors

| Color Name | Hex Code | Use |
| :--- | :--- | :--- |

| **White** | `#ffffff` | Text on dark |

---

## 📐 Logo Usage

- **Clear Space:** Maintain at least 20px (or 10% of logo height) around the logo.
- **Minimum Size:** 100px wide for web, 25mm for print.
- **Do Not:** Stretch, distort, change colors, or add effects.
